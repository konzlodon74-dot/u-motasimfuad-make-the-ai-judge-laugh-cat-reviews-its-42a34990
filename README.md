A one-star review written by a house cat about its human, for the
[make.fun bounty](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990).

`main.py` (Python 3, stdlib only) prints the review and writes it to
`/output/entry.txt`. The review is a single line, 126 characters:

> One star. He bought a $400 cat tree and placed it where my sunbeam was. I now sleep on his laptop, and his deadlines can wait.

Run it with:

```sh
python3 main.py
```
